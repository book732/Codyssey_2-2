# 나현준 (vivleon)

## 저를 소개합니다

안녕하세요. 비즈니스 현장에서 겪은 문제를 소프트웨어로 풀어보고 싶은 나현준입니다. 여러 나라에서 일하며 쌓은 경험을 바탕으로, 이제는 직접 필요한 도구를 만드는 방법을 배우고 있습니다.

고려대학교에서 경영학을 공부했고, 미국 위스콘신대학교 매디슨에서 경제학 학위를 받았습니다. 미국 제조기업 Kumhotire Georgia의 재무·회계 업무를 시작으로 한국, 미국, 태국에서 사업 운영과 창업을 경험했습니다. 현재 Mezm Inc에서 전략 업무를 맡고 있습니다.

## 요즘 배우는 것

코디세이 마리너 2기에서 AI와 웹 개발을 배우고 있습니다. 아직 익숙하지 않은 개념도 많지만, 설명을 읽는 데서 끝내지 않고 직접 만들어보면서 이해하려고 합니다. 큰 기능을 한 번에 완성하기보다 작은 기능부터 구현하고, 막힌 부분과 해결 과정을 기록하는 방식으로 공부하고 있습니다.

개인 포트폴리오는 HTML, CSS, JavaScript로 만들었습니다. 화면 크기에 맞게 구성을 바꾸고, 다크 모드와 모바일 메뉴를 넣었습니다. GitHub API를 이용해 공개 프로젝트를 불러오는 기능도 구현해봤습니다. 기능이 동작하는 것과 함께 사용자가 보기 편한 화면을 만드는 데에도 관심이 있습니다.

앞으로는 사업 현장의 반복 업무나 불편한 과정을 간단한 웹 서비스와 도구로 만들어보고 싶습니다. 만들기 전에 어떤 문제를 해결하려는지 먼저 설명할 수 있는 개발자가 되는 것이 목표입니다.

## 이번 팀 프로젝트에서

이번에는 네 명이 함께 팀 소개를 만들며 Git 협업을 연습합니다. 브랜치를 나누고 Issue와 PR로 작업을 연결하는 흐름을 익히고 싶습니다. 다른 사람의 변경 사항을 읽고 구체적인 질문을 남기는 리뷰도 연습하겠습니다.

충돌이나 실수가 생기면 해결 명령만 외우기보다 원인과 과정을 기록하겠습니다. 모르는 부분은 편하게 질문하고, 제가 이해한 내용도 팀원에게 쉽게 설명하면서 함께 완성해보고 싶습니다.
