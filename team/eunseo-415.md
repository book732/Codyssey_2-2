## 소개

### RMIT University에서 시작한 개발

호주 멜버른의 RMIT University에서 Software Engineering을 전공했습니다. 요구사항 분석부터 설계, 구현, 테스트까지 소프트웨어가 만들어지는 전 과정을 배웠고, 다양한 국적의 동료들과 영어로 팀 프로젝트를 진행하며 협업의 기본기를 익혔습니다. 언어와 문화, 일하는 방식이 서로 다른 환경에서 명확한 문서화와 투명한 공유가 얼마나 중요한지 몸으로 배웠고, 이 경험은 지금도 제가 협업할 때 가장 중요하게 여기는 기준이 되었습니다.

### 한국에서 쌓은 백엔드와 앱 개발 경험

2023년 한국으로 돌아온 뒤에는 Java와 Spring 기반의 백엔드 개발자로 실무를 경험했습니다. API 설계와 데이터베이스 연동, 서버 로직 구현을 다루며 실제 사용자가 있는 서비스에서는 단순히 동작하는 코드가 아니라 유지보수하기 쉽고 안정적인 코드가 중요하다는 것을 체감했습니다. 이후에는 백엔드에 머무르지 않고 Flutter로 모바일 앱을 개발하고 배포까지 경험하며, 사용자 화면부터 서버까지 하나의 서비스가 만들어지는 전체 흐름을 이해하게 되었습니다. 서로 다른 기술 스택을 오가며 새로운 기술도 공식 문서와 작은 실습부터 시작하면 충분히 익힐 수 있다는 자신감을 얻었습니다.

### AI Native와 FDE에 대한 관심

요즘 가장 관심을 두고 있는 분야는 AI Native 개발과 FDE(Forward Deployed Engineer)입니다. AI를 보조 도구로 쓰는 데서 그치지 않고, 처음부터 AI를 전제로 서비스와 개발 프로세스를 설계하는 방식이 앞으로의 표준이 될 것이라고 생각합니다. 또한 고객의 현장에 가까이에서 실제 문제를 정의하고, 기술을 빠르게 적용해 눈에 보이는 가치로 만들어 내는 FDE의 역할에 큰 매력을 느낍니다. 결국 좋은 기술은 실제 문제를 해결할 때 의미가 있다고 생각하기 때문입니다. 백엔드와 앱 개발 경험, 그리고 글로벌 환경에서의 소통 경험이 이 역할에서 강점이 될 수 있다고 믿습니다.

### Codyssey에서의 목표

Codyssey에서는 Python CLI와 Git 기반 협업을 다시 기초부터 다지며, 경험에 의존하기보다 근본 원리를 이해하는 데 집중하고 있습니다. AI 도구도 적극 활용하되, 생성된 결과를 그대로 받아들이지 않고 직접 이해하고 검증한 코드만 반영하려고 합니다. 문제의 원인을 끝까지 분석하고 해결책을 실행으로 옮기는 개발자로서, 팀원들과 함께 배우며 AI 시대에 더 나은 서비스를 만드는 엔지니어로 성장하고자 합니다.
