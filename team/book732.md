## 게임 개발 경험

안녕하세요. 저는 30세 정근혁입니다. 게임을 만들고, 함께 작업하는 과정을 더 잘 정리하는 데 관심이 있습니다. Unity를 활용한 RTS 프로젝트에서는 유닛 이동과 게임 시스템을 다뤘고, 여러 사람이 같은 게임 상태를 볼 수 있도록 네트워크 동기화 방식도 고민했습니다. 메이플스토리 월드 프로젝트를 진행하면서는 아이디어를 실제 플레이 흐름으로 옮기는 과정에 집중했습니다. 기능이 동작하는 것에서 그치지 않고, 사용자가 어떤 순서로 경험하는지 살펴보며 개선점을 찾으려고 합니다.

## 개발 방식

게임 개발에서는 눈에 보이는 결과와 내부 구조를 함께 생각합니다. 유닛 이동을 구현할 때에도 입력을 누가 처리하고, 상태를 어디에서 바꾸며, 다른 플레이어에게 어떤 결과를 보여줄지 살펴봅니다. 이런 질문을 정리하면 오류를 찾고 팀원에게 설명하기 수월합니다. 배우는 내용은 직접 확인하고 의견을 구하겠습니다. 맡은 일의 진행 상황과 남은 문제를 공유해 팀 전체 일정이 보이도록 하겠습니다.

## 팀 프로젝트와 협업

현재 Codyssey 팀 프로젝트에서는 팀장을 맡아 Git과 GitHub를 활용한 협업 방식을 익히고 있습니다. 저장소를 만들고 팀원을 초대했으며, 작업을 Issue로 나누고 브랜치에서 수정한 내용을 Pull Request로 검토하는 흐름을 정리하고 있습니다. 브랜치 이름과 커밋 메시지 규칙을 문서로 남긴 것도 팀원들이 작업 내역을 쉽게 이해하고 이어받을 수 있도록 하기 위해서입니다. 저는 팀장이 혼자 모든 것을 결정하기보다, 각자의 작업이 분명하게 보이고 서로 의견을 주고받을 수 있는 환경을 만드는 것이 중요하다고 생각합니다.

이번 과제에서는 저장소와 브랜치 규칙 관리, Issue별 작업 배분과 PR 리뷰 조율, 팀 문서와 제출 자료 정리를 맡고 있습니다.

## 학습과 목표

Python CLI 과제를 통해서는 작은 기능도 입력, 처리, 결과를 구분해 설계하고 확인하는 연습을 하고 있습니다. 새로운 도구를 접하면 먼저 실제로 사용해 보고, 막히는 부분은 원인을 찾아 기록하며 다음 작업에 적용하려고 합니다. 앞으로는 게임 개발 경험과 협업 경험을 함께 쌓아, 기능의 완성도뿐 아니라 팀이 유지하고 발전시키기 쉬운 결과물을 만드는 사람이 되고 싶습니다.
